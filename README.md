# 贴图 Skill

把参考图片变成原创的公众号 3:4 贴图，并生成配套标题和文案。

作者：[萤柳 Yingliu](https://github.com/Yingliu-design)

## 可以做什么

- 从单张图片、参考文件夹或 Finder 截图定位素材并创作。
- 依据参考的媒介、传播机制、信息密度和情绪，创作新的画面。
- 支持摄影质感、插画、信息图、手写清单和多宫格。
- 输出完整不透明的 3:4 PNG，以及含标题和正文的文案文件。
- 支持单张与批量任务；只有明确要求成套时才合并为一组。

## 安装

把这个仓库的链接发给支持 Skill 的 AI 助手，让它安装「贴图」Skill。

也可以手动下载仓库，将包含 `SKILL.md` 的整个文件夹放入工具的个人 skills 目录。在 Codex 中，常见目录是 `~/.codex/skills/贴图/`。

## 使用

附上参考图，然后说：

> 用「贴图」Skill，按这张参考图做一张原创贴图，图片和文案都要。

批量制作：

> 用「贴图」Skill，按这个文件夹的参考图逐张制作，每张分别保存图片和文案。

多图成套：

> 用「贴图」Skill，把这几张参考图做成一套组图。

需要具备图片读取、图像生成及本地文件保存能力。不同 AI 工具的图像生成接口可能不同，使用时应适配当前工具。

## 输出

公开版默认保存到当前工作目录下的 `贴图/YYYY-MM-DD-NN-短主题/`。参考图优先使用用户指定路径，未指定时查找当前工作目录下的 `贴图参考/`。

每个普通单图任务输出：

- `01-原创贴图.png`
- `02-文案.txt`

可按自己的工作习惯调整 `SKILL.md` 中的输出和参考路径。

生成结果为 AI 生成图。参考图用于理解表达机制，成品需要有明确的新内容，不应直接复刻原图，也不应冒充真实事件或实拍记录。
